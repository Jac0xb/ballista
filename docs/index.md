  - title: Generic composition

  - title: Bounded by construction

    details: One statically bounded account-row iterator supports payroll, distributions, and repeated protocol operations.

## A reusable script for a transaction

Ballista covers the useful middle ground between assembling every instruction in every client and
deploying a bespoke program for every workflow. The author defines a finite orchestration template,
compiles it, and uploads it once. A caller later supplies just the inputs and account rows.

```text
TypeScript template ──compile──▶ immutable template PDA
                                      │
caller + inputs + accounts ──Run──────┴──▶ guarded CPIs ──▶ atomic success or rollback
```

## The smallest useful template

::: code-group

```ts [TypeScript · author]
const transfer = defineTemplate({
  inputs: { amount: { type: 'u64' } },
  accounts: {
    systemProgram: { executable: true, address: SYSTEM_PROGRAM_BYTES },
    sender: { signer: true, writable: true },
    recipient: { writable: true },
  },
  steps: [
    systemTransfer({
      systemProgram: account.fixed('systemProgram'),
      from: account.fixed('sender'),
      to: account.fixed('recipient'),
      lamports: expression.input('amount'),
    }),
  ],
});

const compiled = compileTemplate(transfer);
```

```rust [Rust · call]
use ballista_sdk::run_instruction;
use solana_program::instruction::AccountMeta;

let run = run_instruction(
    template,
    vec![
        AccountMeta::new_readonly(system_program, false),
        AccountMeta::new(sender, true),
        AccountMeta::new(recipient, false),
    ],
    &amount.to_le_bytes(),
);
```

:::
