# Ballista v3 Hardening and Test Suite Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship bytecode version 3 of the Ballista VM with a defensive executor, constant heap, attributable errors, a griefing-proof create path, loop accumulation, and a test suite that proves verifier and executor agree.

**Architecture:** The on-chain program is treated as immutable per deploy, so every wire change lands together as bytecode version 3 and the TypeScript compiler moves with it. Work proceeds host-first: a Rust `ProgramBuilder` and pure-function unit tests establish the baseline, then each on-chain change is made under Mollusk tests, then the SDK is brought to parity with generated fixtures shared by both languages. CI runs everything on pull requests.

**Tech Stack:** Rust 2021 (pinocchio 0.11, zerocopy 0.8, proptest 1.x), Mollusk 0.14 with the token, ATA, and memo programs, TypeScript 7 with Zod 4 and vitest 4, VitePress docs, GitHub Actions.

**Policy assumption (from design review):** each program update is a fresh immutable deploy under a new program ID. Templates are bound to the program that finalized them. The SDK already takes `programAddress` everywhere; the constant `BALLISTA_PROGRAM_ADDRESS` remains the devnet v2 address until v3 is deployed.

**Branch:** `claude/v3-hardening`, based on `codex/ballista-docs` so the docs site config is present.

```rust
//! Typed assembler for Ballista programs. Used by tests, the fuzz generator, and Rust authors.
use zerocopy::IntoBytes;

use super::*;

#[derive(Clone, Copy, Debug)]
pub enum Segment {
    Literal((u16, u16)),
    Register(u8, u8),
}

#[derive(Debug, Default)]
pub struct ProgramBuilder {
    fixed: Vec<AccountConstraint>,
    row: Vec<AccountConstraint>,
    batch_max: u8,
    batch_min: u8,
    flags: u8,
    inputs: Vec<InputDescriptor>,
    instructions: Vec<InstructionRecord>,
    cpis: Vec<CpiDescriptor>,
    cpi_accounts: Vec<CpiAccountRecord>,
    segments: Vec<DataSegment>,
    pubkeys: Vec<PubkeyRecord>,
    blob: Vec<u8>,
    next_register: u8,
}

impl ProgramBuilder {
    pub fn new() -> Self { Self::default() }

    pub fn account(&mut self, flags: u8, address: Option<[u8; 32]>, owner: Option<[u8; 32]>, min_data_len: u32) -> u8 {
        let constraint = self.constraint(flags, address, owner, min_data_len);
        self.fixed.push(constraint);
        (self.fixed.len() - 1) as u8
    }

    pub fn row_account(&mut self, flags: u8, address: Option<[u8; 32]>, owner: Option<[u8; 32]>, min_data_len: u32) -> u8 {
        let constraint = self.constraint(flags, address, owner, min_data_len);
        self.row.push(constraint);
        ITERATION_ACCOUNT_BIT | (self.row.len() - 1) as u8
    }

    pub fn batch(&mut self, max_iterations: u8, min_iterations: u8) -> &mut Self {
        self.batch_max = max_iterations;
        self.batch_min = min_iterations;
        self
    }

    pub fn flags(&mut self, flags: u8) -> &mut Self { self.flags = flags; self }

    pub fn input(&mut self, value_type: u8, max_len: u16) -> u8 {
        self.inputs.push(InputDescriptor { value_type, reserved: 0, max_len_le: max_len.to_le_bytes() });
        (self.inputs.len() - 1) as u8
    }

    pub fn pubkey(&mut self, bytes: [u8; 32]) -> u8 {
        if let Some(index) = self.pubkeys.iter().position(|record| record.bytes == bytes) {
            return index as u8;
        }
        self.pubkeys.push(PubkeyRecord { bytes });
        (self.pubkeys.len() - 1) as u8
    }

    pub fn blob(&mut self, bytes: &[u8]) -> (u16, u16) {
        let offset = self.blob.len() as u16;
        self.blob.extend_from_slice(bytes);
        (offset, bytes.len() as u16)
    }

    /// Allocates the next register index without emitting anything.
    pub fn register(&mut self) -> u8 {
        let register = self.next_register;
        self.next_register += 1;
        register
    }

    /// Emits a raw record and returns its instruction index.
    pub fn emit(&mut self, record: InstructionRecord) -> usize {
        self.instructions.push(record);
        self.instructions.len() - 1
    }

    /// Emits an instruction that writes a fresh register and returns that register.
    pub fn op(&mut self, opcode: u8, a: u8, b: u8, c: u8, immediate: u64) -> u8 {
        let dst = self.register();
        self.emit(record(opcode, dst, a, b, c, 0, immediate));
        dst
    }

    pub fn load_input(&mut self, input: u8) -> u8 { self.op(OP_LOAD_INPUT, input, NO_INDEX, NO_INDEX, 0) }
    pub fn const_u64(&mut self, value: u64) -> u8 { self.op(OP_CONST_U64, NO_INDEX, NO_INDEX, NO_INDEX, value) }
    pub fn const_bool(&mut self, value: bool) -> u8 { self.op(OP_CONST_BOOL, u8::from(value), NO_INDEX, NO_INDEX, 0) }
    pub fn require(&mut self, register: u8) { self.emit(record(OP_REQUIRE, NO_INDEX, register, NO_INDEX, NO_INDEX, 0, 0)); }

    pub fn cpi(&mut self, program: u8, accounts: &[(u8, u8)], segments: &[Segment]) -> u8 {
        let account_start = self.cpi_accounts.len() as u16;
        for (account, flags) in accounts {
            self.cpi_accounts.push(CpiAccountRecord { account: *account, flags: *flags });
        }
        let segment_start = self.segments.len() as u16;
        let mut max_data_len = 0u16;
        for segment in segments {
            max_data_len += self.push_segment(*segment);
        }
        self.cpis.push(CpiDescriptor {
            program_account: program,
            reserved0: 0,
            account_start_le: account_start.to_le_bytes(),
            account_len: accounts.len() as u8,
            segment_len: segments.len() as u8,
            segment_start_le: segment_start.to_le_bytes(),
            max_data_len_le: max_data_len.to_le_bytes(),
            reserved1: [0; 2],
        });
        (self.cpis.len() - 1) as u8
    }

    /// Overrides the declared max data length of a CPI (for negative tests).
    pub fn set_cpi_max_data_len(&mut self, cpi: u8, len: u16) {
        self.cpis[cpi as usize].max_data_len_le = len.to_le_bytes();
    }

    pub fn invoke(&mut self, cpi: u8, condition: Option<u8>) {
        self.emit(record(OP_INVOKE, NO_INDEX, cpi, condition.unwrap_or(NO_INDEX), NO_INDEX, 0, 0));
    }

    /// Emits a FOREACH whose body is produced by `body`; returns the FOREACH index.
    pub fn for_each(&mut self, carry_mask: u64, body: impl FnOnce(&mut Self)) -> usize {
        let index = self.emit(record(OP_FOREACH, NO_INDEX, 0, NO_INDEX, NO_INDEX, 0, carry_mask));
        body(self);
        let body_len = (self.instructions.len() - index - 1) as u8;
        self.instructions[index].a = body_len;
        index
    }

    /// Pushes PDA seed segments and emits DERIVE_PDA.
    pub fn derive_pda(&mut self, program: u8, seeds: &[Segment]) -> u8 {
        let start = self.segments.len() as u64;
        for seed in seeds { self.push_segment(*seed); }
        self.op(OP_DERIVE_PDA, program, NO_INDEX, NO_INDEX, start | ((seeds.len() as u64) << 32))
    }

    pub fn build(&self) -> Result<Vec<u8>, TemplateError> {
        let header = ProgramHeader::new(
            self.fixed.len() as u8,
            self.row.len() as u8,
            self.batch_max,
            self.batch_min,
            self.inputs.len() as u8,
            self.next_register,
            self.instructions.len() as u8,
            self.cpis.len() as u8,
            self.cpi_accounts.len() as u16,
            self.segments.len() as u16,
            self.pubkeys.len() as u8,
            self.flags,
            self.blob.len() as u16,
        );
        let mut bytes = header.as_bytes().to_vec();
        for record in self.fixed.iter().chain(self.row.iter()) { bytes.extend_from_slice(record.as_bytes()); }
        for record in &self.inputs { bytes.extend_from_slice(record.as_bytes()); }
        for record in &self.instructions { bytes.extend_from_slice(record.as_bytes()); }
        for record in &self.cpis { bytes.extend_from_slice(record.as_bytes()); }
        for record in &self.cpi_accounts { bytes.extend_from_slice(record.as_bytes()); }
        for record in &self.segments { bytes.extend_from_slice(record.as_bytes()); }
        for record in &self.pubkeys { bytes.extend_from_slice(record.as_bytes()); }
        bytes.extend_from_slice(&self.blob);
        if bytes.len() > MAX_TEMPLATE_PAYLOAD_LEN { return Err(TemplateError::PayloadTooLarge(bytes.len())); }
        Ok(bytes)
    }

    /// Mutable access to emitted instructions for negative tests.
    pub fn instructions_mut(&mut self) -> &mut Vec<InstructionRecord> { &mut self.instructions }

    fn constraint(&mut self, flags: u8, address: Option<[u8; 32]>, owner: Option<[u8; 32]>, min_data_len: u32) -> AccountConstraint {
        AccountConstraint {
            flags,
            address_index: address.map_or(NO_INDEX, |key| self.pubkey(key)),
            owner_index: owner.map_or(NO_INDEX, |key| self.pubkey(key)),
            reserved: 0,
            min_data_len_le: min_data_len.to_le_bytes(),
        }
    }

    fn push_segment(&mut self, segment: Segment) -> u16 {
        let (record_value, len) = match segment {
            Segment::Literal((offset, len)) => (DataSegment { kind: DATA_LITERAL, register: NO_INDEX, offset_le: offset.to_le_bytes(), len_le: len.to_le_bytes(), reserved: [0; 2] }, len),
            Segment::Register(kind, register) => (DataSegment { kind, register, offset_le: [0; 2], len_le: [0; 2], reserved: [0; 2] }, segment_width(kind)),
        };
        self.segments.push(record_value);
        len
    }
}

pub fn record(opcode: u8, dst: u8, a: u8, b: u8, c: u8, flags: u8, immediate: u64) -> InstructionRecord {
    InstructionRecord { opcode, dst, a, b, c, flags, immediate_le: immediate.to_le_bytes(), reserved: [0; 2] }
}

fn segment_width(kind: u8) -> u16 {
    match kind { DATA_REG_U8 | DATA_REG_BOOL => 1, DATA_REG_U16 => 2, DATA_REG_U32 => 4, DATA_REG_U64 | DATA_REG_I64 => 8, DATA_REG_U128 => 16, DATA_REG_PUBKEY => 32, _ => 0 }
}
```

```rust
        CreateAccount::with_minimum_balance(creator, template, space as u64, &crate::ID, None)?.invoke_signed(&[signer])?;
    } else {
        let required = Rent::get()?.minimum_balance(space);
        let shortfall = required.saturating_sub(template.lamports());
        if shortfall > 0 {
            Transfer { from: creator, to: template, lamports: shortfall }.invoke()?;
        }
        Allocate { account: template, space: space as u64 }.invoke_signed(&[signer.clone()])?;
        Assign { account: template, owner: &crate::ID }.invoke_signed(&[signer])?;
    }
    // write header as before
}
```

### Task 10: Language additions: min iterations, carry, move, dynamic reads

**Files:**
- Modify: `common/src/template/verify.rs`, `programs/ballista/src/processor/execute.rs`, `common/src/template/builder.rs`, `tests/ballista/src/lib.rs`

Verifier rules:

- Header: `batch_min_iterations <= batch_max_iterations`; stride 0 ⇒ min 0; else `InvalidMinIterations`.
- FOREACH carry mask (`immediate`): each set bit `r` must satisfy `r < register_count` and `registers[r].is_some()` before the loop, else `InvalidCarry(r)`. After `verify_range` of the body, `body_registers[r] == registers[r]` else `InvalidCarry(r)`. Bits at or above `register_count` → `InvalidCarry(r)`.
- `OP_MOVE`: `dst := read_register(a)`.
- Instruction flags: only `INSTRUCTION_FLAG_DYNAMIC_OFFSET` and only on `OP_READ_*`; when set, `b` must be a `VALUE_U64` register and `immediate` must be 0; other opcodes with any flag → `InvalidFlags(index)`.

Executor:

- `validate_runtime_accounts`: `if iterations < header.batch_min_iterations() { return Err(vm_error(InvalidAccountRange, iterations as u16)); }`
- FOREACH: after each body, `for r in 0..registers.len() { if carry & (1 << r) != 0 { base_registers[r] = registers[r]; } }` then restore.
- `OP_MOVE`: `set(registers, dst, get(registers, instruction.a)?)?`.
- Reads: `let offset = if instruction.flags & INSTRUCTION_FLAG_DYNAMIC_OFFSET != 0 { match get(registers, instruction.b)? { RuntimeValue::U64(v) => usize::try_from(v).map_err(|_| BallistaError::InvalidRuntimeAccount)?, _ => return Err(BallistaError::TypeMismatch.into()) } } else { instruction.immediate() as usize };`

Builder: `pub fn mov(&mut self, dst: u8, src: u8)`, `pub fn read_dynamic(&mut self, opcode: u8, account: u8, offset_register: u8) -> u8`.

1. Compile steps first, then account records, so inferred `minDataLength` (max of declared and every static read's `offset + width`) is known.
